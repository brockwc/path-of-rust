# Learning workspace (ramp-up)

Ramp-up work for the capstone: Rustlings, The Rust Book (chapters 1-13), and three small CLI
programs. Each CLI program gets its own crate in this folder and is added to the workspace
`members` list in the root `Cargo.toml` once it starts.

Planned programs:

1. Word frequency counter: file input, HashMap, sorting, output formatting
2. Dice and damage calculator: enums, traits, a small RNG crate dependency
3. CSV line filter: error handling with Result, iterators, CLI argument parsing

Each program is committed with tests and is part of the weekly progress evidence.
